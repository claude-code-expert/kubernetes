01무엇을 만드는가

메트릭이 “무언가 이상하다”를 알려주고, 로그가 “무슨 일이 있었나”를 알려주고, 알림이 사람을 부른다. 그 셋이 한 화면에 모인 상태를 노트북 한 대 안에서 만든다. 클라우드 계정도 별도 VM (Virtual Machine · 가상 머신) 도 필요 없다.

그리고 마지막 장에서 일부러 고장을 낸다. 만들어 둔 알림이 실제로 우는지, 대시보드가 그것을 보여 주는지 판정하지 않으면 관측 체계가 동작한다고 말할 수 없기 때문이다.

이 과정이 다루는 것다루지 않는 것
메트릭 수집과 PromQL (Prometheus Query Language · 프로메테우스 질의 언어), 대시보드, 알림, 로그 수집, 카오스 실험분산 추적, 장기 저장, 멀티 클러스터 — 10장 부록 D 에 이어지는 주제로 적어 뒀다

04각 장의 구성

열한 장이 같은 뼈대를 쓴다. 두 번째 회차부터는 필요한 블록만 골라 읽으면 된다.

블록무엇이 들어 있나
왜 이 장이 필요한가앞 장의 결과가 왜 부족한지에서 출발한다
알아야 할 개념실습에서 마주칠 개념만. 끝에 용어표 — 영문 풀네임과 역할을 함께 적는다
학습 목표이 장을 마치면 무엇을 할 수 있는지
최종적으로 만들 것도판과 그 아래 확인 명령 + 기대값. 그리고 WHY 블록이 그 그림을 만드는 설정 파일의 경로와 발췌를 보여 준다
따라하기목적 → 명령 → 옵션 설명 → 실행 결과 → 판정
일부러 실패시키기실제로 겪을 실수를 재현하고 에러 메시지를 읽은 뒤 고친다
자주 겪는 문제증상과 첫 번째로 볼 곳
부록 A · B · C완료 체크리스트(명령 + 기대값) · 명령어 레퍼런스 · 참고 출처
도판 뒤에는 항상 근거가 온다

그림을 보고 “그래서 저게 왜 저렇게 되는가”가 남지 않도록, 모든 도판 뒤에 그 그림을 만드는 설정 파일의 저장소 경로와 해당 부분 발췌, 그리고 설정 한 줄이 그림의 무엇이 되는지를 짝지은 표를 둔다. 문서만 보고 실습해도 이해가 끊기지 않게 하려는 구성이다.

실행 결과는 지어내지 않는다

문서에 실린 출력은 전부 실제로 실행해 얻은 것이다. 값이 환경마다 다른 부분(IP (Internet Protocol · 네트워크에서 주소를 정하는 규약) · 파드 접미사 · 타임스탬프)은 그대로 두고 각주를 달았다. 확인하지 못한 출력은 싣지 않고 “이런 형태의 출력이 나온다”고 서술했다.

06버전

이 시리즈의 실행 결과는 아래 조합에서 실제로 실행해 얻은 것이다. 버전을 올리면 화면이 달라질 수 있으므로, 문서의 출력과 대조하려면 이 조합을 그대로 쓴다.

구성요소버전함정
Kubernetes / kind1.36.x / v0.32.0kubeadm 설정은 v1beta4 — 맵이 아니라 목록이다
kube-prometheus-stack차트 88.xOperator v0.91 계열. CRD (Custom Resource Definition · 쿠버네티스 API 를 확장해 만든 리소스 타입) 는 helm upgrade 로 갱신되지 않는다

Loki3.7.x차트 저장소는 grafana 가 아니라 grafana-community
로그 수집기Grafana AlloyPromtail 은 2026-03-02 EOL (End Of Life · 지원이 끝나 더는 고쳐지지 않는 상태). 검색 결과에 아직 나오지만 쓰지 않는다
Chaos Meshv2.8.2kind 에서는 chaosDaemon.runtime=containerd 가 없으면 실험이 조용히 아무 일도 하지 않는다

38편 과정과 버전이 다르다

같은 저장소의 도커 & 쿠버네티스 38편 과정은 2026-09-03 기준 1.37.0 · kind v0.33.0 · 차트 89.2.2 로 고정돼 있다. 이 시리즈를 1.37 라인으로 올리려면 11장의 명령과 출력을 다시 검증해야 하므로, 검증된 조합을 그대로 유지하고 차이를 여기 적어 둔다. 두 과정을 같은 클러스터에서 섞어 돌리지 않는다.

하드웨어

Docker Desktop 에 CPU (Central Processing Unit · 중앙처리장치) 4코어 · 메모리 10 GiB (Gibibyte · 2의 30제곱 바이트. 쿠버네티스가 쓰는 단위) 이상을 할당한다. 10 GiB 미만이면 04장 설치에서 반드시 막힌다. 메모리가 12 GiB 미만이면 01장에서 워커를 하나로 줄이는 선택지가 있다 — 그 경우 라벨 두 개를 같은 노드에 붙인다.
