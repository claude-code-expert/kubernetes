우분투와 윈도우에서 도구 설치

본문의 실습과 실행 결과는 macOS 기준이다. 다른 운영체제에서 도구를 갖추는 절차만 여기에 모았다.

먼저 알아 둘 것

이 문서는 도구 설치까지만 다룬다. 설치가 끝나면 00장의 헬름 저장소 등록부터 이어서 진행한다. 본문에 실린 실행 결과(버전 숫자, 경로)는 맥에서 얻은 것이므로 화면이 조금 다를 수 있다 — 판정 기준은 같다.

02Ubuntu 22.04 / 24.04

1. Docker Engine

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker "$USER"   # 로그아웃 후 재로그인 필요
docker 그룹의 의미

docker 그룹에 넣는 것은 사실상 root 권한을 주는 것이다. 도커 소켓에 접근할 수 있으면 호스트 파일 시스템을 통째로 마운트한 컨테이너를 띄울 수 있기 때문이다. 개인 실습 머신에서는 편의를 택해도 되지만, 공용 서버라면 rootless 모드를 검토한다.

2. kubectl

KVER="$(curl -sL https://dl.k8s.io/release/stable.txt)"
curl -LO "https://dl.k8s.io/release/${KVER}/bin/linux/amd64/kubectl"
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
rm -f kubectl

3. kind

# arm64 머신이면 kind-linux-arm64 로 바꾼다
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.32.0/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind

4. Helm

curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3
chmod 700 get_helm.sh
./get_helm.sh
rm -f get_helm.sh

5. JDK 21 과 jq

sudo apt-get update
sudo apt-get install -y openjdk-21-jdk jq

03Windows — WSL2 위에서

파워셸에서 직접 하지 않는다

윈도우에서는 WSL2 안의 우분투를 실습 환경으로 쓴다. 파워셸에서 직접 진행하면 볼륨 마운트와 cgroup 문제로 시간을 버린다.

# PowerShell (관리자 권한)
wsl --install -d Ubuntu-24.04
wsl --set-default-version 2

설치가 끝나면 Docker Desktop 의 Settings → Resources → WSL Integration 에서 해당 배포판을 켠다. 그다음 우분투 셸에 들어가 위 02절의 2~5번(kubectl · kind · Helm · JDK)을 그대로 실행한다. Docker Engine 은 Docker Desktop 이 제공하므로 우분투 안에서 따로 깔지 않는다.

04설치 확인

docker version --format '{{.Server.Version}}'
kubectl version --client -o yaml | grep gitVersion
kind version
helm version --short
java -version
jq --version

여섯 줄이 모두 값을 내면 준비가 끝난 것이다. 이어서 00장의 헬름 저장소 등록과 사전 점검 스크립트를 진행한다.

cgroup v2 확인

Kubernetes 1.35부터 cgroup v1 지원이 제거됐다. 다음 명령이 cgroup2fs 를 내야 한다.

stat -fc %T /sys/fs/cgroup
← 목차 장 목록으로 이어서 → 00 · 실습 환경 준비와 버전 고정
