캡처를 슬라이드에 붙이는 방법

라이브 데모 슬라이드에는 이미지 자리가 따로 없다. 캡처는 데모가 막혔을 때 꺼내 보이는 예비 화면으로 붙는다.

  1. 캡처 파일을 images/에 슬라이드 번호로 저장한다. 예: 슬라이드 54 → images/s54.png. 한 슬라이드에 여러 장이면 s58.png, s58-2.png, s58-3.png.
  2. 다시 빌드한다: python3 src/build.py (출력 마지막 줄 앞에 captures attached: N)
  3. 발표 중 그 슬라이드에서 오른쪽 아래 캡처 N · C 버튼을 누르거나 C 키를 누르면 캡처가 슬라이드 위에 뜬다. 여러 장이면 C를 누를 때마다 다음 장, Esc나 클릭으로 닫는다. 방향키로 넘어가면 자동으로 닫힌다.
