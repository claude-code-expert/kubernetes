# 글로벌 롤아웃 체크리스트와 사고 대응 러너북 (M32)

이 문서는 사람이 새벽에 읽는다. 설명이 아니라 **순서**를 적는다.

## A. 롤아웃 전 체크리스트

- [ ] CI 가 통과했다 (`.github/workflows/ci.yaml` — 테스트·스캔·차트 검사, M29)
- [ ] 이미지 태그가 **커밋 SHA** 다. `latest` 나 재사용 태그가 아니다 (M26·M29)
- [ ] 모든 리전의 클러스터에 그 이미지가 있다 (사설 레지스트리라면 복제가 끝났는가)
- [ ] 리전마다 **전제 구성요소가 같은가** — metrics-server · 인그레스 컨트롤러 · CRD
      (M32 실패 ②: edge 에 metrics-server 가 없어 HPA 가 죽고 앱이 Degraded 였다)
- [ ] 되돌릴 커밋을 미리 확인했다: `git log --oneline -5`
- [ ] 이 변경이 **스키마·데이터 마이그레이션을 포함하는가**. 포함하면 롤백이 코드 되돌리기로 끝나지 않는다

## B. 롤아웃 순서

1. 카나리 리전에만 배포한다 (저장소의 `regions/<canary>/` 만 고친다)
2. `scripts/region-check.sh <컨텍스트> <네임스페이스> <기대 이미지>` 가 **통과**할 때까지 기다린다
3. 통과하지 못하면 **확산하지 않는다.** D 로 간다
4. 통과하면 관측을 본다 — 에러율·P99·재시작 수 (M20~M21 의 대시보드)
5. 최소 관찰 시간을 지킨다. 짧으면 느린 누수(메모리·커넥션)를 놓친다
6. `base/` 를 올려 나머지 리전으로 확산한다
7. 각 리전마다 다시 2번을 돌린다

## C. 확산 중 판단 기준

| 신호 | 조치 |
|---|---|
| 카나리 리전의 에러율이 기준을 넘었다 | 즉시 D. 다른 리전은 건드리지 않는다 |
| 한 리전만 느리다 | 그 리전의 자원·노드를 본다. 코드 문제가 아닐 수 있다 |
| 롤아웃이 진행되지 않는다 (`rollout status` 타임아웃) | 이미지·리소스·어드미션 순으로 확인 (M24·M26) |
| 지표가 안 보인다 | 판정할 근거가 없는 상태다. **확산을 멈춘다** |

## D. 롤백 절차

되돌리는 방법은 **커밋을 되돌리는 것** 하나다. 클러스터를 손으로 고치면
GitOps 컨트롤러가 5초 뒤 되돌려 놓는다 (M31 실패 ③).

```
# 1) 무엇을 되돌릴지 정한다
git log --oneline -5

# 2) 되돌린다 — 히스토리를 지우지 않고 반대 커밋을 쌓는다
git revert --no-edit <커밋>

# 3) 밀어 넣는다
git push          # 실습에서는 scripts/gitops-push.sh

# 4) 반영을 확인한다 (실측: 8초)
kubectl --context <컨텍스트> -n <네임스페이스> \
  get deploy journal-api -o jsonpath='{.spec.template.spec.containers[0].image}'

# 5) 건강한지 확인한다
scripts/region-check.sh <컨텍스트> <네임스페이스> <되돌린 이미지>
```

`git reset` 이 아니라 `git revert` 를 쓰는 이유: 무슨 일이 있었는지가 이력에 남아야 한다.
사고 후 회고에서 "언제 무엇을 되돌렸나"를 저장소에서 읽을 수 있어야 한다.

## E. 긴급 상황에서 GitOps 를 잠시 끄기

커밋을 기다릴 수 없을 때만. 끄면 **다시 켜는 것을 잊지 않도록** 알림을 걸어 둔다.

```
# 자동 동기화 해제
kubectl -n argocd patch application journal-<리전> --type=json \
  -p '[{"op":"remove","path":"/spec/syncPolicy/automated"}]'

# ... 응급 조치 ...

# 반드시 되돌린다: 손으로 한 것을 커밋한 뒤 자동 동기화를 다시 켠다
kubectl -n argocd patch application journal-<리전> --type=merge \
  -p '{"spec":{"syncPolicy":{"automated":{"prune":true,"selfHeal":true}}}}'
```
